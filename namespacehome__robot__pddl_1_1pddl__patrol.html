Detailed Description

PDDL patrol controller with execution monitoring and replanning.

Generates a PDDL problem from waypoints, calls the POPF planner binary directly, parses the plan, and executes move actions against Nav2. If the robot gets stuck, it performs a recovery manoeuvre (backs up for ~1 s) and replans from the new state.
