Detailed Description

Sends a NavigateToPose goal to Nav2 and monitors progress.

Inherits from yasmin_ros.ActionState to handle the full action lifecycle (goal / feedback / result) automatically.

Outcomes (inherited + custom): succeeded — navigation completed successfully. aborted — Nav2 aborted the goal. canceled — navigation was canceled externally.
