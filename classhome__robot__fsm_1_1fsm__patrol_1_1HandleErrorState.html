Detailed Description

Handles navigation failures.

If skip_errors is enabled in the blackboard, the state transitions to recover (try the next waypoint). Otherwise it aborts the patrol.

Outcomes: recover — skip this waypoint, try the next one. abort — stop the patrol entirely.
