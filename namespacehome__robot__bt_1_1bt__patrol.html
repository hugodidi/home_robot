Detailed Description

Custom Behavior Tree patrol node.

This implementation owns the patrol behavior tree instead of delegating the patrol logic to Nav2's BT Navigator. Nav2 is still used as the navigation action backend, but selection, fallback, recovery and event publication are implemented as local BT nodes.
