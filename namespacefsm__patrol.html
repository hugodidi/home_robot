Detailed Description

Launch file for the FSM Patrol system.

Starts the YASMIN-based waypoint patrol node and opens the YASMIN Viewer web interface.

Usage: ros2 launch home_robot_fsm fsm_patrol.launch.py ros2 launch home_robot_fsm fsm_patrol.launch.py random:=true ros2 launch home_robot_fsm fsm_patrol.launch.py random:=true skip_errors:=true

Prerequisites: The home_robot navigation stack must already be running: ros2 launch home_robot main_nav.launch.py use_slam:=true
